# w

`w` is for *wishes*: code we wish was part of another library. Each subpackage
is named after the library it extends and would live upstream if we could put
it there. The code is the documentation.

| Package | Wish for |
|---|---|
| `internal/w/kong` | `github.com/alecthomas/kong` |
| `internal/w/maps` | `maps` |
| `internal/w/slices` | `slices` |
| `internal/w/time` | `time` |
